# 📊 รายงานผล LLM Judge (Golden Set)

ไฟล์ `judge-<PROMPT_VERSION>-<timestamp>.json` ในโฟลเดอร์นี้สร้างด้วย:

```bash
npm run ai:judge                           # ครบ 30 เคส
npm run ai:judge -- --limit 3              # รันเร็วตอนพัฒนา
npm run ai:judge -- --compare 20260904-1   # เทียบกับเวอร์ชันก่อน
```

**ทำไมต้อง commit ไฟล์รายงานเข้า repo**: ทุกงานในคลื่น B ต้องแนบผลเทียบก่อน/หลัง
ถ้าไม่เก็บ baseline ไว้ที่นี่ รอบหน้าจะไม่มีอะไรให้เทียบ แล้วคำว่า "ดีขึ้น" จะกลายเป็นความรู้สึกล้วน ๆ
(ดู `docs/plans/HANDOFF_AI_ACCURACY_THAI_2026-09-07.md` หัวข้อ 8)

⚠️ สคริปต์นี้ยิงเข้าโมเดลจริงด้วยคีย์ของนักพัฒนา — **รันด้วยมือเท่านั้น**
ห้ามผูกเข้า CI · ห้ามผูกเข้า `repo:verify` · ห้ามให้แตะเพดาน AI ของ production
(ด่านที่อยู่ใน `repo:verify` คือโหมด `--dry-run` ซึ่งไม่เรียกโมเดลเลย)
