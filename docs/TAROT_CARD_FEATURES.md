## 1. เส้นทางการเปิดไพ่หนึ่งครั้ง

```mermaid
flowchart TD
    Q["ผู้ใช้เลือกผัง · ตั้งคำถาม · เลือกแม่หมอ"] --> S{"ด่านความปลอดภัย"}
    S -- "สัญญาณทำร้ายตัวเอง" --> H["หยุด · แสดงสายด่วน 1323"]
    S -- "ผ่าน" --> C["เซิร์ฟเวอร์สร้าง serverSeed และส่งคำมั่น SHA-256 ให้ก่อน"]
    C --> F["ผู้ใช้สับไพ่ (ได้ clientSeed) แล้วแตะเลือกไพ่จากพัด 78 ใบเอง"]
    F --> B["ไพ่วางบนผังแบบคว่ำหน้า"]
    B --> R["ผู้ใช้แตะพลิกไพ่ทีละใบ"]
    R --> AI["แม่หมอ AI อ่านไพ่ที่ออกจริงแบบสตรีม"]
    AI --> P["เฉลย serverSeed · ผู้ใช้ตรวจย้อนหลังในเบราว์เซอร์ได้"]
```

- ขั้นตอนบนหน้าเว็บ (`src/components/home/ritual-step.ts`): เลือกผัง ➔ ตั้งคำถาม/เลือกแม่หมอ ➔ สับ ➔ เลือกไพ่ ➔ อ่าน ➔ สรุป
- ต้องลงชื่อก่อนเปิดไพ่ · สิทธิ์ฟรีและเพดานอยู่ใน `src/lib/entitlement/limits.ts` (ดูหัวข้อ 4.2)

## 3. ความหมาย 5 หมวด

ไพ่ทุกใบมีความหมายครบ 5 หมวด ทั้งหัวตั้งและกลับหัว ทั้งไทยและอังกฤษ = 78 × 5 × 2 = 780 ข้อความต่อภาษา (ตรวจ 2026-10-27: ครบ ไม่มีช่องว่าง)

```typescript

export interface Interpretation {
  upright: string;  // หัวตั้ง 2-4 ประโยค
  reversed: string; // กลับหัว 2-4 ประโยค
}

export interface TarotCard {
  id: string;                    // "major-00", "wands-01"

  nameTh: string;
  nameEn: string;

  numerology: string;            // + numerologyEn
```

1. ก่อนผู้ใช้แตะไพ่ เซิร์ฟเวอร์สุ่ม `serverSeed` 32 ไบต์ แล้วส่ง `commitment = SHA-256(serverSeed)` ให้ก่อน
2. ผู้ใช้สับไพ่ ได้ `clientSeed` จากการขยับจริง (ต้องไม่ว่าง เซิร์ฟเวอร์ห้ามสุ่มแทน)
3. เซิร์ฟเวอร์สับสำรับด้วย Fisher–Yates จากเมล็ด `SHA-256(serverSeed|clientSeed)` (สายเลขสุ่ม `SHA-256(seed:counter)` · rejection sampling กันความเอนเอียง · โอกาสกลับหัว 40%) แล้วหยิบตามตำแหน่งในพัดที่ผู้ใช้แตะ
4. อ่านจบแล้วเฉลย `serverSeed` · เบราว์เซอร์คำนวณซ้ำเองด้วย Web Crypto (`src/lib/tarot/verify-client.ts`) ต้องได้ไพ่ชุดเดิมทุกใบ

```typescript
// rejection sampling ใน src/lib/tarot/shuffle.ts — กันไพ่ใบต้นสำรับออกบ่อยกว่าใบท้าย
nextInt(maxInclusive: number): number {
  if (maxInclusive <= 0) return 0;
  const range = maxInclusive + 1;
  const limit = Math.floor(0x1_0000_0000 / range) * range;
  let value: number;
  do {
    value = this.nextUint32();
  } while (value >= limit);
  return value % range;
}
```
