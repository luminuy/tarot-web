## กติกากันงานหาย (ทุกเอเจนท์ต้องทำ)
1. เอเจนท์ **ตรวจอย่างเดียว ไม่แก้โค้ด** — ผู้คุมงานเป็นคนแก้ (กันชนกันเอง) · เขียนได้แค่ไฟล์ผลของตัวเองในโฟลเดอร์นี้
2. เจอข้อค้นพบ 1 ข้อ ➔ **เขียนต่อท้ายไฟล์ของตัวเองทันที** ไม่เก็บไว้ในหัว
3. ตรวจเสร็จแต่ละโฟลเดอร์ ➔ เขียน `- [x] <path>` ในหัวข้อ "ความคืบหน้า" ของไฟล์ตัวเอง
4. ถ้าเริ่มใหม่ ➔ อ่านไฟล์ตัวเองก่อน ข้ามโฟลเดอร์ที่ติ๊กแล้ว
5. ห้ามรัน `next build` / `next dev` / `npm run build` ในโฟลเดอร์หลัก (ผลบิลด์ `.next/` `dist/` ใช้ร่วมกัน) — ต้องการเซิร์ฟเวอร์ให้ใช้พอร์ตของตัวเอง
6. production (`seertarot.net`) ยิงได้เฉพาะ GET หน้า/ส่วนหัวสาธารณะ ห้ามยิง payload โจมตี · พิสูจน์ช่องโหว่ในเครื่องเท่านั้น
7. ข้อที่ตั้งใจไว้แล้ว (มีใน `INCIDENT_LOG` · `KNOWN_ISSUES` · แผน) ไม่ต้องรายงานซ้ำ · ข้อที่รอบ 2026-09-23 ปิดไปแล้วแต่กลับมาพัง = รายงานเป็น "ถอยหลัง (regression)"
