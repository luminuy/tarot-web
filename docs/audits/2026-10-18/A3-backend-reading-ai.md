### 🟠 A3-02 · คำถามที่มี `</3` (อีโมติคอนอกหัก) ถูกนับเป็น "พยายามฉีดคำสั่ง" — ลองซ้ำ 3 ครั้งโดนพักเปิดไพ่+แชท 1 ชม. ทั้งบัญชีและ "ทุกคนที่ใช้ IP เดียวกัน"
- ที่: `src/lib/ai/prompt-guard.ts:53` (`/<\s*\//`) · `src/lib/security/abuse-guard.ts:20-21,32-58` (ตัวตน = IP ดิบ + บัญชี) · `src/app/api/reading/start/route.ts:161-167` · `src/app/api/reading/[id]/chat/route.ts:178-183`
- ปัญหา: (1) ด่าน tag-injection จับ `</` ทุกที่ จึงจับ `</3` ซึ่งเป็นอีโมติคอน "อกหัก" ที่คนพิมพ์ในคำถามความรักจริง (2) `/start` ตอบกลับแค่ "ข้อมูลที่ส่งมาไม่ถูกต้อง" (ไม่บอกว่าผิดตรงไหน) ผู้ใช้จึงกดซ้ำ (3) ครบ 3 ครั้งใน 1 ชม. ➔ `inj_cool` ถูกตั้งให้ทั้ง `ip:<IP>` และ `u:<userId>` (4) `isInInjectionCooldown` บล็อกถ้า "ตัวตนใดตัวตนหนึ่ง" ติดพัก ➔ สมาชิกคนอื่นที่ออกเน็ตผ่าน IP เดียวกัน (CGNAT มือถือ AIS/True/DTAC · Wi-Fi ออฟฟิศ/มหาลัย/หอ) โดนพักไปด้วย
- ผลกระทบ/สถานการณ์พัง: คนอกหักพิมพ์ "อกหักมาก </3 เขาจะกลับมาไหม" ➔ 400 ไม่บอกเหตุ ➔ กดอีก 2 ครั้ง ➔ "ระบบขอพักการเปิดไพ่จากการเชื่อมต่อนี้ชั่วคราว" 1 ชม. ทั้งเปิดไพ่และถามต่อ · คนอื่นใน CGNAT เดียวกันเปิดไพ่ไม่ได้ 1 ชม. โดยไม่ได้ทำอะไร · ผู้ไม่ประสงค์ดีที่อยู่ใน IP ร่วมก็ทำให้คนทั้งเครือข่ายเปิดไพ่ไม่ได้ได้ด้วยคำขอ 3 ครั้ง (ไม่ต้องล็อกอิน · ด่าน `isRequestAuthorizedOrigin` กันแค่ CSRF)
- หลักฐาน: รันในเครื่อง (`scratchpad/a3/inj.ts` · `cool.ts`): `looksLikePromptInjection("อกหัก </3 จะลืมเขาได้ไหม") = true` · `"Will he come back? </3" = true` · `noteInjectionAttempt` 3 ครั้งด้วย IP 203.0.113.7 ผู้ใช้ `u_heartbroken` ➔ ครั้งที่ 3 `tripped=true` · `isInInjectionCooldown(IP เดียวกัน, "u_innocent_neighbor") = true` · ชุดคำถามปกติใน `test-ai-security`/`test-prompt-injection` ไม่มีเคส `</3`
- แนวแก้: ยกเว้น `</3`/`<\3` ใน `looksLikeTagInjection` (หรือจับเฉพาะ `</` ตามด้วยตัวอักษร เช่น `/<\s*\/\s*[a-z_]/i`) แล้วเพิ่มเคสนี้ในชุดคำถามปกติ · พักด้วยตัวตนบัญชีเมื่อมี userId (ใช้ IP เฉพาะคำขอไม่ล็อกอิน และควรนับต่อซับเน็ต/แฮชพร้อมเพดานสูงกว่า) · `/start` ส่งข้อความ zod ที่บอกว่า "มีอักขระที่ไม่อนุญาต" กลับไปแทนข้อความกลาง
