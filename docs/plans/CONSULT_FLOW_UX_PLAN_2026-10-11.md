## 2. หลักออกแบบ 7 ข้อ (แบบหน้าจองของ Airbnb · Calendly · Agoda · Grab)

1. **ทุกจอมีปุ่มหลักปุ่มเดียว เห็นตลอด ไม่มีอะไรบัง** (ปิดปุ่มลอยในหน้ากลุ่มแม่หมอ)
2. **ห้ามปุ่มจางแบบเงียบ** — ปุ่มกดได้เสมอ ขาดอะไรให้พาไปจุดนั้นพร้อมบอกด้วยคำพูดว่าขาดอะไร
3. **เวลาเร็วที่สุดขึ้นก่อน** — คนส่วนใหญ่อยากคุยเร็วที่สุด ให้แตะครั้งเดียวจบ
4. **หน้าจองเต็มจอบนมือถือ ไม่ใช่หน้าต่างลอย** · ปุ่มย้อนกลับของเบราว์เซอร์ = ถอยหนึ่งขั้น (ไม่หลุดออกจากหน้า)
5. **ภาษาคน**: "คุยตอนนี้" / "นัดเวลา" / "ชื่อและคำถาม" — ไม่ใช่ "คิวสด walk-up"
6. **ลูกค้าไม่หลุดกลางทาง**: ลิงก์นัดเปิดได้ทุกเบราว์เซอร์ทุกเครื่อง · มีทางออกจากเบราว์เซอร์ในแอปพร้อมพานัดไปด้วย
7. **แม่หมอเห็นก่อนส่งลิงก์ว่าลูกค้าจะเจออะไร** (คุยได้เลย / ได้แค่นัด / จองไม่ได้เลย) และแก้ได้จากจุดเดียวกัน

## 4. ขั้นตอนใหม่ฝั่งแม่หมอ (แผงแม่หมอ)

- การ์ด **"ส่งลิงก์ให้ลูกค้า"** บนสุด: ลิงก์หน้าจอง + ปุ่มคัดลอก + ปุ่มส่งทาง LINE + **บอกว่าลูกค้าที่เปิดตอนนี้จะเห็นอะไร**
  - เปิดคิวสดอยู่ ➔ "ลูกค้ากด 'คุยตอนนี้' ได้ทันที"
  - ปิดคิวสดแต่มีตาราง ➔ "ตอนนี้ลูกค้าจองได้แค่เวลานัด เร็วสุด <วัน เวลา> — จะคุยเลยให้เปิดรับคิวสดก่อนส่งลิงก์" + ปุ่มเปิดรับคิวสด
  - ไม่มีทั้งสองอย่าง ➔ เตือนว่า "ลูกค้าที่เปิดลิงก์ตอนนี้จะจองไม่ได้เลย"
- ตั้งค่า **"รับนัดล่วงหน้าอย่างน้อย"**: 30 นาที · 1 ชม. · **2 ชม. (ค่าเริ่มต้น ตามที่เคาะ 2026-10-03)** · 3 · 6 · 12 ชม. · 1 วัน
  — ด่านฝั่งเซิร์ฟเวอร์ (`generateSlots` / `slotRejection`) ใช้ค่าเดียวกัน ไคลเอนต์ส่งเวลาที่สั้นกว่านี้มาก็ถูกปฏิเสธ

## 7. กับดักที่ห้ามพลาด

- **ห้ามเชื่อเวลาที่ไคลเอนต์ส่งมา** — เวลาเร็วที่สุด/ลิงก์ `?slot=` เป็นแค่ทางลัดหน้าจอ เซิร์ฟเวอร์ตรวจด้วย `checkSlotBookable` ทุกครั้งเหมือนเดิม
- **`accessUrl` ส่งให้เจ้าของตั๋วเท่านั้น** — ห้ามส่งให้แม่หมอ (ลิงก์นี้แลกเป็นคุกกี้ `customerRef` ได้ = เห็นทุกนัดของลูกค้าคนนั้น · บทเรียน A2-13)
- **ห้ามเลื่อนแนวนอน** ในแถววัน (กฎเหล็กข้อ 3 · คอมเมนต์เดิมใน `SlotPicker`) — ใช้แบ่งหน้า ‹ › แทน
- หน้าจองเป็นหน้าใหม่ของ Next ➔ ต้องมี `<SiteHeader />` `<SiteFooter />` (INC-0112) · `noindex` · อยู่ใต้ `/readers/*` ใน `run_worker_first` แล้ว
- `openExternalBrowser=1` ใช้ได้กับแอป LINE เท่านั้น — แอปอื่นต้องบอกวิธีกดเปิดเอง + ปุ่มคัดลอกลิงก์
- นโยบายยกเลิก/คืนเงิน **ไม่เปลี่ยนในรอบนี้** (คลื่น 3.1 รอเจ้าของ)
- **`sessionSecret` ห้ามออกนอกเซิร์ฟเวอร์** แม้แต่ไปหน้าแอดมิน — คำตอบของ API แอดมินต้องผ่าน `toAdminReader()` เสมอ (ด่าน 19.8)
- ปุ่ม "เปิดแผงแม่หมอ" ต้อง `window.open` **ก่อน** `await` ขอลิงก์ — เปิดหลัง await เบราว์เซอร์บล็อกเป็นป๊อปอัป (ถ้าโดนบล็อกจะโชว์แผงลิงก์ให้กดเองแทน)
- แผงแม่หมอ: คำตอบ 401 **หลังจากมีข้อมูลแล้ว** = ลิงก์หมดอายุกลางคิว ห้ามล้างหน้า (ห้องวิดีโอจะดับ) — แสดงแถบเตือนแทน
- วิดีโอทั้งสองภาพต้อง `object-contain` — `object-cover` ตัดขอบเฟรม ไพ่ริมโต๊ะหลุดกรอบทั้งจอแม่หมอและจอลูกค้า (ด่าน 19.7)
