## 3. ระดับเอฟเฟกต์ 3 ชั้น — หัวใจของ UI 2.0

### 3.1 นิยาม

`<html data-fx="full | lite | off">` ตั้งโดยสคริปต์บรรทัดเดียวใน `<head>` **ก่อนวาดเฟรมแรก** (ทั้ง `astro/layouts/BaseLayout.astro` และ `src/app/_shared/RootHtml.tsx` ของหน้าที่ยังเป็น Next)

| ระดับ | ใครได้ | หน้าตา |
| :--- | :--- | :--- |
| `full` | คอม · แท็บเล็ต/iPad (จอ ≥ 768px) ที่ไม่ใช่เครื่องสเปกต่ำ | ทุกอย่างตามภาพต้นแบบ D+ |
| `lite` | มือถือ · จอสัมผัสที่ด้านสั้น < 600px · เครื่อง RAM ≤ 4GB (`navigator.deviceMemory` มีเฉพาะ Chromium) · โหมดประหยัดข้อมูล · เครื่องที่ตกเกณฑ์ FPS (3.3) | หน้าตาเดียวกัน แต่ใช้ของที่วาดครั้งเดียว (ตาราง 3.4) |
| `off` | `prefers-reduced-motion: reduce` | นิ่งทั้งหน้า ไม่มีอนิเมชันวน ไม่มีเลื่อนแล้วโผล่ |

```html
<script is:inline>
  (function () {
    var d = document.documentElement, fx = "full";
    try {
      var mq = function (q) { return window.matchMedia(q).matches; };
      var n = navigator, c = n.connection;
      if (mq("(prefers-reduced-motion: reduce)")) fx = "off";
      else if (sessionStorage.getItem("ui2-fx") === "lite") fx = "lite";
      else if (mq("(max-width: 767px)") || (mq("(pointer: coarse)") && Math.min(screen.width, screen.height) < 600)) fx = "lite";
      else if ((n.deviceMemory && n.deviceMemory <= 4) || (c && c.saveData)) fx = "lite";
    } catch (e) { fx = "lite"; }
    d.setAttribute("data-fx", fx);
  })();
</script>
```

- **ห้ามใช้ `navigator.hardwareConcurrency`** แยกเครื่องแรง/อ่อน — Safari บน iPad รายงานค่าไม่ตรง iPad จะโดนลดเป็น `lite` ผิด ๆ ทั้งที่เจ้าของสั่งให้ iPad ได้เต็ม
- ไม่มี JS (หรือสคริปต์พัง) = ไม่มี `data-fx` ➔ CSS ต้องได้หน้าตา `lite` (ค่าตั้งต้นปลอดภัย)

### 3.2 วิธีเขียน CSS — ล็อกสองชั้น

```css
/* ค่าตั้งต้น = lite ทุกเครื่อง */
.ui2-glass { background: var(--ui2-glass-fill-solid); }

/* ของหนักต้องผ่านทั้งสองชั้น: ระดับ full และจอกว้างจริงตอนนี้ */
@media (min-width: 768px) {
  [data-fx="full"] .ui2-glass { background: var(--ui2-glass-fill); backdrop-filter: blur(22px) saturate(170%); }
}
[data-fx="off"] * { animation: none !important; transition: none !important; }
```

ชั้น `@media (min-width: 768px)` กันเคส iPad แบ่งจอ (Split View) หรือหมุนจอจนแคบ — ของหนักหลุดเองโดยไม่ต้องรันสคริปต์ใหม่

**ของหนักทั้งหมดต้องอยู่ในไฟล์เดียว** เช่น `src/styles/ui2-fx-full.css` ทุกกฎในไฟล์ขึ้นต้นด้วย `[data-fx="full"]` — ด่านตรวจได้ง่าย (หัวข้อ 7)

### 3.3 ตัวกันพัง FPS (สำหรับ "เดี๋ยวมีปัญหาได้")

หลังหน้า hydrate เสร็จ ถ้าเป็นระดับ `full` ให้วัดเวลาเฟรมด้วย `requestAnimationFrame` **2 วินาทีแล้วหยุด** (ไม่ใช่ลูปถาวร — ด่าน motion กฎ 3) ถ้าค่ากลางของเฟรม > 22ms (ต่ำกว่า ~45fps) ➔ ตั้ง `data-fx="lite"` ทันที และจำไว้ใน `sessionStorage` (`ui2-fx`) ห่อ try/catch · ส่ง event วัดผล `ui2_fx_downgrade` เพื่อดูว่าเกิดกับเครื่องไหนบ้าง

### 3.4 เอฟเฟกต์ × ระดับ

| เอฟเฟกต์ | `full` (คอม · iPad) | `lite` (มือถือ) | `off` |
| :--- | :--- | :--- | :--- |

| วงแหวนทองหมุน | หมุน 140 วินาทีต่อรอบ | หมุนได้ (SVG ชิ้นเดียว · transform) หยุดเมื่อพ้นจอ | นิ่ง |

> 🚨 **พื้นหลังส่วนปิดท้ายห้ามใช้ `filter: blur()` กับภาพไพ่หลายใบ แม้ระดับ full** — ทำภาพประกอบเบลอสำเร็จรูปไฟล์เดียวตอนบิลด์ (≤ 60KB WebP) ได้หน้าตาเหมือนกันทุกระดับและถูกกว่ามาก (ภาพต้นแบบใช้ filter เพราะเป็นแค่ภาพร่าง)

**หยุดอนิเมชันเมื่อพ้นจอ** — ทุกส่วนที่มีอนิเมชันวนใส่ `data-anim-section` แล้วให้ `IntersectionObserver` ตัวเดียวสลับ `data-inview`:

```css
[data-anim-section]:not([data-inview]) * { animation-play-state: paused; }
```

## 5. มือถือ — กติกาเฉพาะ (ส่วนที่เจ้าของย้ำ)

### 5.1 จอแรก

- **ปุ่มหลัก "เปิดไพ่ด่วน 1 ใบ" ต้องอยู่ภายใน 600px แรก** ที่ 390×844 (พื้นที่ที่เห็นจริงใน Safari มีราว 660px เมื่อแถบเครื่องมือโผล่) — ภาพต้นแบบมือถือปุ่มอยู่ราว 640–700px **เกินไป** ให้แก้:
  - ระยะเหนือหัวข้อ 150 ➔ 88px · h1 34px
  - นาฬิกานับถอยหลังในหัวหน้า ย่อเป็น **ชิปบรรทัดเดียว** ใต้ปุ่ม: "ไพ่ประจำวันใบใหม่ใน 09:42:17" (นาฬิกาตัวใหญ่ไปอยู่ส่วนปิดท้ายอย่างเดียว)
  - ปุ่มรอง "ไพ่วันนี้ · ชื่อไพ่" อยู่ใต้ปุ่มหลัก
- การ์ดลอย 4 ใบ เกาะมุมจอ (ล้นขอบได้) ห้ามทับหัวข้อหรือปุ่ม
- **ภาพที่ใหญ่ที่สุดในจอแรกต้องไม่ใช่ภาพไพ่** — LCP คือ h1 (ภาพการ์ดลอยใช้ `fetchPriority="low"` แบบ `hero-fan` ตอนนี้)

### 5.2 ระหว่างเลื่อน

- หลังเลื่อนพ้นหัวหน้า แสดง **แถบปุ่มติดล่างจอ** "เปิดไพ่ด่วน 1 ใบ" (ใช้แบบเดียวกับแถบเปิดไพ่ติดล่างจอของหน้าความหมายไพ่ #657) · เว้น `env(safe-area-inset-bottom)` · **ห้ามทับปุ่มแชทลอยมุมขวาล่าง** และซ่อนเมื่อส่วนที่ 3 หรือส่วนที่ 8 อยู่ในจอ (มีปุ่มเดียวกันอยู่แล้ว)
- ริบบิ้นที่เอียงกว้างเกินจอ ต้องถูกตัดด้วย `overflow-x: clip` ที่ส่วนนั้น — **ห้าม `overflow-x: hidden` ที่ `body`** (INC-0067: หัวเว็บ sticky พัง)
- ส่วนทดลองแตะไพ่: ปุ่มเรื่อง 4 ปุ่มเป็นตาราง 4 ช่อง สูง ≥ 64px · ผ้าปูไพ่สูง 270px · ไพ่แต่ละใบเป็น `<button>` กว้างพอให้นิ้วแตะ (≥ 44px)
- กระดาษโน้ต 2 คอลัมน์ นิ่ง · กล่องฟีเจอร์ซ้อนกันคอลัมน์เดียว
- ตัวหนังสือเนื้อความ ≥ 15px · ช่องกรอก ≥ 16px (กัน iPhone ซูม) · บรรทัดภาษาไทย line-height ≥ 1.6

### 6.9 คีย์เฟรมที่ใช้ (ยกจากภาพต้นแบบ — แตะแค่ transform / opacity / background-position)

```css
@keyframes ui2-drift   { 0%,100% { transform: translate(0,0) scale(1) } 50% { transform: translate(90px,50px) scale(1.18) } }
@keyframes ui2-bob     { 0%,100% { translate: 0 0 } 50% { translate: 0 -16px } }
@keyframes ui2-shimmer { from { background-position: 0% 50% } to { background-position: 200% 50% } }  /* full เท่านั้น */
@keyframes ui2-spin    { to { transform: rotate(360deg) } }
@keyframes ui2-marquee { from { transform: translateX(0) } to { transform: translateX(-50%) } }
@keyframes ui2-pulse   { 0% { transform: scale(.55); opacity: .95 } 100% { transform: scale(1.9); opacity: 0 } }
@keyframes ui2-rise    { from { opacity: 0; translate: 0 90px; scale: .94 } to { opacity: 1; translate: 0 0; scale: 1 } }
@keyframes ui2-draw    { from { stroke-dashoffset: 420 } to { stroke-dashoffset: 0 } }

@supports (animation-timeline: view()) {
  .ui2-reveal { animation: ui2-rise linear both; animation-timeline: view(); animation-range: entry 0% cover 26%; }
}
```

- ค่าตั้งต้นของทุก element = ตำแหน่งสุดท้าย (คีย์เฟรมมีแค่ `from`) — เบราว์เซอร์ที่ไม่รองรับจึงเห็นของครบ ไม่หายไปไหน
- คีย์เฟรมที่ใช้กับของที่จัดกลางด้วย `translate` ของ Tailwind ห้ามมี `translate(%)` ซ้ำ (ด่าน motion กฎ 9 · INC-0123)
- ไพ่พลิก: `transform: rotateY(180deg)` บน `transform-style: preserve-3d` + transition 1s `cubic-bezier(.2,.85,.2,1)` — ถ้าจะใช้ custom property ใน transform ต้องประกาศ `@property` (ด่าน motion กฎ 8)

| # | กับดัก | ทางกัน |
| --: | :--- | :--- |
| 1 | ลอกภาพต้นแบบที่ผูกไพ่กับหัวข้อ (ความรัก = คู่รักเสมอ) | ภาพร่างสาธิตเท่านั้น — ไพ่มาจาก `/shuffle` อย่างเดียว (6.3) |
| 2 | ใส่ `backdrop-filter` หรือ blur นอกระดับ full "เพราะในคอมลื่นดี" | มือถือคือที่ที่ INC-0056 เกิด (30 ➔ 58fps เมื่อถอด) · ของหนักอยู่ไฟล์เดียวใต้ `[data-fx="full"]` |
| 3 | ตั้งระดับเอฟเฟกต์ใน React หลัง hydrate | หน้าแวบเป็น full แล้วค่อยลด = กระตุก + CLS · ต้องเป็นสคริปต์ใน `<head>` ก่อนวาด |
| 4 | ใช้ `hardwareConcurrency` แยกเครื่องอ่อน | iPad โดนลดผิด ๆ (หัวข้อ 3.1) |
| 5 | ใช้ `filter: blur` กับภาพไพ่หลายใบในส่วนปิดท้าย | ภาพเบลอสำเร็จรูปไฟล์เดียว |
| 6 | ทองวิ่งบนพื้นสว่างใช้จุดสว่างแบบภาพร่างเดิม | ใช้ `--ui2-gold-light` (6.1.1) |
| 7 | ป้ายบนกระจกผ่านด่าน a11y แต่จริงอ่านไม่ออก | วัดสีที่ผสมแล้ว ณ จุดมืดที่สุด (6.1.1) |
| 8 | ตัดส่วนเดิมทิ้งแล้วลิงก์ภายในหายไปด้วย | เทียบ `href` ก่อน-หลัง (6.7) |
| 9 | ริบบิ้นเอียงทำให้หน้าเลื่อนแนวนอนได้บนมือถือ → แก้ด้วย `overflow-x: hidden` ที่ body | ห้าม (INC-0067) — ใช้ `overflow-x: clip` ที่ส่วนนั้น |
| 10 | นาฬิกาเรนเดอร์ตัวเลขจริงตั้งแต่เซิร์ฟเวอร์ | hydration ไม่ตรง + เลขค้างจากตอนบิลด์ — เซิร์ฟเวอร์ส่ง `--:--:--` |
| 11 | ลืมว่าหน้าแรกมี `/en` ด้วย | ข้อความใหม่ทุกจุดต้องมีภาษาอังกฤษ ตามอภิธานศัพท์ใน `HANDOFF_EN_TRANSLATION_2026-09-06.md` |
| 12 | หน้าต่างลอยที่เปิดจากส่วนพื้นมืดถูกส่วนถัดไปทับ | หน้าต่างลอยเต็มจอวาดผ่าน `createPortal` ไป `document.body` เสมอ (INC-0243) |

## 11. คำถามที่ยังเปิด — ถามเจ้าของก่อนถึงขั้นนั้น

1. กล่อง "คุยกับแม่หมอตัวจริง" จะโชว์แม่หมอคนไหน (คะแนนสูงสุด · ว่างเร็วที่สุด · เจ้าของเลือกเอง)
2. ฟอนต์ลายมือบนกระดาษโน้ต (Itim) คุ้มกับน้ำหนักฟอนต์ที่เพิ่มไหม หรือใช้ Anuphan
3. หัวเว็บเปลี่ยนเป็นกระจกมืดเมื่ออยู่เหนือส่วนพื้นมืด (แบบ fastwork) — เอาหรือไม่
4. คลื่น 3 (หน้าอื่น) เริ่มหน้าไหนก่อน
