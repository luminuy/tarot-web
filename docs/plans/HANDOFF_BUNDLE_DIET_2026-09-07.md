## 3. งานที่ต้องทำ

### 🅦-01 · `motion` ถูกโหลดบนทุกหน้า แม้หน้าที่ไม่มีแอนิเมชันเลย 🔴

**หลักฐาน** — chunk `1524-*` (40 KB gzip) ปรากฏบน **ทุกหน้า** รวม `/blog` · `/privacy` · `/cards/all`
ต้นเหตุคือ `RootHtml` ครอบทั้งเว็บด้วย `AppMotionProvider` ซึ่ง `import { MotionConfig } from "motion/react"`

```tsx
// src/app/_shared/RootHtml.tsx
<AppMotionProvider>
  <LocaleProvider …>
```

**ทางแก้ที่แนะนำ** — ย้าย `AppMotionProvider` ลงไปครอบเฉพาะต้นไม้ที่ใช้แอนิเมชันจริง
(`TarotFlow` · `OneCardRitual` · modal ทั้งหมด) แทนการครอบทั้ง `<body>`
`MotionConfig` มีผลกับ subtree ที่ครอบเท่านั้น ค่า `reducedMotion="user"` จึงยังทำงานเหมือนเดิม

> ⚠️ **สำคัญ** — การย้าย provider อย่างเดียว**ไม่พอ** ถ้ายังมีคอมโพเนนต์ที่อยู่บนทุกหน้า
> `import { motion } from "motion/react"` ตรง ๆ · ต้องไล่ดูให้ครบก่อน:
> ```bash
> for f in $(grep -rl 'from "motion/react"' src --include='*.tsx'); do
>   echo "$f"; done
> ```
> คอมโพเนนต์ที่อยู่ในเปลือกทุกหน้า (`SiteHeader` · `SiteFooter` · `SacredNavDropdown` ·
> `AnnouncementBanner` · `TikTokFloatingButton`) **ต้องไม่ใช้ `motion` เลย** —
> แอนิเมชันระดับ fade/slide ธรรมดาใช้ CSS `transition` แทนได้ทั้งหมด

**เกณฑ์ผ่าน**
- chunk ที่มี `motion` **ไม่ปรากฏ**บน `/blog` · `/privacy` · `/cards/all` · `/spreads/topic/*`
- `/blog` ≤ **235 KB** (ค่าที่ผู้ใช้จริงโหลด · ไม่นับ polyfills)
- แอนิเมชันในหน้าเปิดไพ่ (สับไพ่ · พัดไพ่ · พลิกไพ่) **เหมือนเดิม 100%** — ต้องเดินพิธีกรรมจริงดูก่อน merge
- `prefers-reduced-motion` ยังถูกเคารพ

### 🅦-02 · ข้อมูลผัง 25 แบบเต็มถูกลากเข้าทุกหน้าโดยโมดูลค่าคงที่ 🔴

**หลักฐาน** — [`src/lib/entitlement/limits.ts:32`](../../src/lib/entitlement/limits.ts)

```ts
import { SPREADS } from "@/data/spreads";   // ← ไฟล์ต้นทาง 85 KB

export const STANDARD_SPREAD_IDS: ReadonlySet<string> = new Set(
  SPREADS.filter((s) => s.guestAllowed).map((s) => s.id)   // ← ใช้แค่ id 10 ตัว
);
```

`limits.ts` ถูก import โดยคอมโพเนนต์ที่อยู่บนทุกหน้า (ป้ายโควตาบนหัวเว็บ)
→ ข้อมูลผังทั้ง 25 แบบพร้อมทุกตำแหน่งและคำอธิบาย เข้าไปอยู่ในบันเดิลของ `/blog` · `/privacy` ด้วย

**นี่คือบั๊กแบบเดียวกับ P-01 เป๊ะ ๆ** (`nav-links.ts` ลาก `DECK` มาเพื่อนับเลข 3 ตัว)
ต่างแค่คราวนี้ลากมาเพื่อเอา **id 10 ตัว**

**ทางแก้** — ต้องคง Single Source of Truth ไว้ (INC-0005) จึงใช้แพตเทิร์นเดียวกับที่ P-01 ใช้:

1. สร้าง `src/data/spreads/standard-ids.generated.ts` ที่มีแต่ id 10 ตัว (ไม่ import อะไรเลย)
2. `limits.ts` อ่านจากไฟล์นั้นแทน — **ห้าม `import { SPREADS }` อีก**
3. เพิ่มการยืนยันในด่าน `test-feature-gating.ts` (ฝั่งเซิร์ฟเวอร์ ไม่กระทบบันเดิล):

```ts
assert(
  [...STANDARD_SPREAD_IDS].sort().join(",") ===
    SPREADS.filter((s) => s.guestAllowed).map((s) => s.id).sort().join(","),
  "STANDARD_SPREAD_IDS ต้องตรงกับ guestAllowed ใน SPREADS เสมอ",
);
```

> ✅ วิธีนี้ยังคงกฎ INC-0005 ครบ — ความจริงยังอยู่ที่ `SPREADS` เพียงที่เดียว
> แค่ย้ายการ "ตรวจสอบ" จาก compiler ไปเป็นด่าน CI ซึ่งเป็นแพตเทิร์นที่คลังนี้ใช้อยู่แล้ว

**เกณฑ์ผ่าน**
- chunk ที่มีสตริง `celtic-cross` **ไม่ปรากฏ**บน `/blog` · `/privacy` · `/cards/[id]`
- `/blog` ลดลงอีก ~17 KB
- `npm run repo:verify` ผ่านครบ · ด่านผังฟรียังยืนยันได้ว่า 10 ผังตรงกับ `guestAllowed`

### 🅦-04 · ลิงก์ 23 จุดตั้ง `prefetch={false}` ทำให้กดแล้วต้องรอโหลด 🟡

**หลักฐาน** — `grep -rn "prefetch={false}" src --include='*.tsx' | wc -l` → **23**

เดิมตั้งไว้เพื่อกัน prefetch avalanche (INC-0088) แต่ตอนนี้มี **Speculation Rules API**
ใน `RootHtml` คุมการอุ่นหน้าอยู่แล้ว การปิด prefetch ซ้ำจึงทำให้ผู้ใช้เสียประโยชน์เปล่า ๆ

**ทางแก้** — ไล่ดูทีละจุด แล้วเปิด prefetch เฉพาะลิงก์ที่**อยู่ในสายตาผู้ใช้และมีโอกาสถูกกดสูง**
(เมนูหลัก · ปุ่ม CTA · ไพ่ใบก่อน/ถัดไป) · คงปิดไว้สำหรับลิงก์ในฟุตเตอร์และตารางไพ่ 78 แถว
ซึ่งเป็นต้นเหตุ avalanche เดิม

**เกณฑ์ผ่าน** — จำนวนคำขอ prefetch ตอนโหลดหน้าแรก **ไม่เกิน 5 รายการ** (ดูใน DevTools → Network)
· `/cards` และ `/spreads` ยังไม่เกิดคำขอนับสิบรายการตอนเลื่อนหน้า

## 5. วิธีวัดซ้ำ (ใช้ตัวเลขเดียวกับแผนนี้)

```bash
npm run build && node -e '
const fs=require("fs"),zlib=require("zlib");
function measure(page){
  const html=fs.readFileSync(".next/server/app/"+page,"utf8");
  const all=[...new Set(html.match(/_next\/static\/chunks\/[^"]+\.js/g)||[])];
  let real=0,total=0;
  for(const c of all){
    const b=fs.readFileSync(".next/"+c.replace(/^_next\//,""));
    const g=zlib.gzipSync(b).length; total+=g;
    if(!c.includes("polyfills")) real+=g;   // noModule — ผู้ใช้จริงไม่โหลด
  }
  return [real,total];
}
for(const p of ["index.html","cards.html","blog.html","spreads.html","cards/all.html","cards/birth-card.html"]){
  const [r,t]=measure(p);
  console.log(p.padEnd(24),(r/1024).toFixed(0)+"KB (จริง) /",(t/1024).toFixed(0)+"KB (รวม polyfills)");
}'
```
