### 3.1 หัวข้อ — ลำดับไม่ข้าม

`h1` หัวหน้า ➔ `h2` ชื่อหมวด ×6 ➔ `h3` ชื่อผังบนไพ่ (26 ใบ) ➔ `h2` สารบัญ / แยกตามเรื่อง / ทางลัด · ในหน้าต่างไพ่เด้งชื่อผังเป็น `h2` ของ `<dialog>` (หัวข้อ 5)

### 3.2 ชื่อผังบนไพ่

ใช้ `nameTh` ตัดท้าย `(ไพ่ N ใบ)` ออก (จำนวนอยู่บนป้ายหัวไพ่แล้ว) ด้วยตัวช่วยใหม่ใน `spreads-helpers.ts` · วงเล็บที่ไม่ใช่จำนวน เช่น "(เซลติกครอส)" ให้คงไว้ · **สารบัญท้ายหน้าใช้ `nameTh` เต็มเหมือนเดิม** (ข้อความลิงก์ที่ Google เห็นอยู่ตอนนี้)

### 3.3 ห้ามทำลิงก์หาย

ก่อนแก้ ดึง `href` ภายในทั้งหมดจาก `dist/spreads/index.html` และ `dist/en/spreads/index.html` เก็บไว้ ➔ หลังแก้ต้องครอบคลุมทุกเส้นเดิม (ตอนนี้ `/spreads/*` 33 เส้น) · ไพ่ทุกใบเป็นลิงก์ `<a href="/spreads/<id>">` อยู่แล้ว (หัวข้อ 4.1) สารบัญยังต้องอยู่ เพราะเป็นรายการเดียวที่ลิงก์ครบโดยไม่พึ่ง JS และเป็นข้อความเต็ม

## 4. ไพ่ผัง (หนึ่งผัง = ไพ่หนึ่งใบ)

### 4.1 โครงสร้าง

```html
<a class="ui2-spread-card" href="/spreads/love" data-spread-id="love" style="--cat: var(--ui2-note-3); --cat-ink: var(--ui2-note-ink-3)">
  <span class="ui2-sc-count">5 ใบ</span>                          <!-- ป้ายหัวไพ่ สีหมวด -->
  <span class="ui2-sc-lock"><svg …/><span class="sr-only">ผังพิเศษ</span></span>   <!-- เฉพาะ !isStandardSpread(id) -->
  <span class="ui2-sc-window" aria-hidden="true">…ไพ่คว่ำตามตำแหน่งจริง…</span>
  <h3 class="ui2-sc-band">ดวงความรักสองหัวใจ</h3>                 <!-- แถบชื่อ สีหมวด -->
</a>
```

- เป็น `<a>` จริง — ไม่มี JS (หรือสคริปต์ล้ม) = กดแล้วไปหน้าคู่มือผัง · มี JS = เปิดไพ่เด้ง (หัวข้อ 5) · กดพร้อม Ctrl / ⌘ / Shift หรือคลิกกลาง = ปล่อยให้เปิดแท็บใหม่ตามปกติ
- ป้ายผังพิเศษใช้เงื่อนไขเดิม `!isStandardSpread(spread.id)` · คำบนจอ "ผังพิเศษ" (เดิม "ญาณพิเศษ" — เปลี่ยนเป็นภาษาคน กฎเหล็ก 10)

## 5. ไพ่เด้ง — แตะแล้วเปิดหน้าต่างผัง

### 5.1 โครงสร้าง

- `<dialog class="ui2-spread-pop" aria-labelledby="spread-pop-title">` **ตัวเดียว** วางท้าย `<main>` นอกส่วนหมวดทุกส่วน (ไม่ติด stacking context ของส่วนไหน — เหตุผลเดียวกับ INC-0243) เปิดด้วย `show()` ในชั้นลอย `data-floating` + ฉากหลังของเราเอง ดัก Tab/Esc/คลิกฉากหลังเอง (เดิมใช้ `showModal()` — ทำให้คำนวณสไตล์ใหม่ทั้งหน้าทุกครั้งที่เปิด เฟรมยาว 190–342 ms ที่ CPU ×4 · INC-0301 · 2026-10-21)
- เนื้อหาในหน้าต่างสร้างจากไพ่ที่แตะ: **คัดลอกหน้าต่างผ้าปูจากไพ่ใบเล็ก** (`cloneNode`) ขยายเป็นไพ่ใหญ่ + เติมเลขตำแหน่ง ไม่เรนเดอร์ผังซ้ำ 26 ชุดลง HTML (งบ DOM)
- ข้อความรายตำแหน่ง (ชื่อตำแหน่ง) ต้องอยู่ใน HTML ของไพ่แต่ละใบอยู่แล้ว (`<ol hidden data-positions>` ใต้ไพ่ — ตอนนี้มีอยู่ใน `<details>` และ Google เห็น) สคริปต์ย้ายมาแสดงในหน้าต่าง
- ปิด: ปุ่มกากบาท (`aria-label="ปิด แล้วกลับไปเลือกไพ่ใบอื่น"`) · Esc · แตะพื้นหลัง · มือถือมีปุ่ม "กลับไปเลือกไพ่ใบอื่น" ท้ายหน้าต่าง · ปิดแล้วโฟกัสกลับไปที่ไพ่ใบเดิม
- ลิงก์ลึก: เปิด `/spreads#spread-<id>` แล้วหน้าต่างของผังนั้นเปิดเอง · เปิด/ปิดหน้าต่างใช้ `history.replaceState` (ไม่เพิ่มประวัติ ปุ่มย้อนกลับไม่ติดค้าง)

### 5.2 ในหน้าต่าง

| คอม / iPad (≥ 768px) | มือถือ (< 768px) |
| :--- | :--- |
| ไพ่ใหญ่กว้าง 300px ซ้าย + แผงข้อมูลกว้างไม่เกิน 560px ขวา · พื้นหลังมืด 0.72 | แผ่นเลื่อนขึ้นจากล่างสูงไม่เกิน `92dvh` มุมบนโค้ง 30px · ไพ่ใหญ่ 230px กลางบน ข้อมูลอยู่ใต้ไพ่ · ปุ่มเริ่มติดล่าง (`env(safe-area-inset-bottom)`) |

แผงข้อมูล: ชิปชื่อหมวด (สีหมวด) · ชิป "{n} ใบ" · ชิป "ผังพิเศษ" (ถ้าใช่) · `h2` ชื่อผังเต็ม · `tagline` · รายการตำแหน่ง (เลขทองตัวตรง · ผังเกิน 6 ใบแบ่ง 2 คอลัมน์บนคอม) · ชี้ที่แถวตำแหน่งแล้วไพ่ใบนั้นในผ้าปูเรืองทอง (คอมเท่านั้น) · ปุ่มหลักขอบทองหมุน **"เริ่มดูดวงด้วยผังนี้"** ➔ `/read/<id>` (เส้นทางเดิม ด่านสิทธิ์ทำงานที่หน้านั้นตาม INC-0216) · ปุ่มรอง **"อ่านคู่มือผังนี้"** ➔ `/spreads/<id>`

### 5.3 จังหวะเด้ง

```css
@keyframes ui2-pop-flip {
  0%   { opacity: 0; transform: perspective(1400px) translateY(120px) rotateY(85deg) rotateZ(-10deg) scale(.55) }
  55%  { opacity: 1; transform: perspective(1400px) translateY(-14px) rotateY(-10deg) rotateZ(2deg) scale(1.05) }
  100% { opacity: 1; transform: none }
}
/* ไพ่ใหญ่ 0.85s cubic-bezier(.2,.85,.2,1) · แผงข้อมูลเลื่อนเข้าจากขวา 40px หน่วง 0.25s · วงแสงทองหลังไพ่เต้น 2.4s */
```

- แตะ `transform` / `opacity` เท่านั้น · ระดับ `off` (ลดการเคลื่อนไหว) = จางเข้า 0.2s ไม่หมุน
- `-webkit-backface-visibility` เขียนคู่เสมอ · ตรวจขอบกะพริบบน Safari ตอนหมุน (UI 2.0 แผนหลัก หัวข้อ 4)
