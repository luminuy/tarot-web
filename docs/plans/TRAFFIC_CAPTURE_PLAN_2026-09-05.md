## 1.1 ดีมานด์จริงจาก Google Autocomplete

แหล่ง: `suggestqueries.google.com/complete/search?hl=th&gl=th` — Google เรียงคำแนะนำ**ตามความถี่การค้นหาจริง**

**พิมพ์ "ดูดวงไพ่" →**
```
1. ดูดวงไพ่ยิปซี              6. ดูดวงไพ่ทาโร่      ← สะกด "ทาโร่" ไม่ใช่ "ทาโรต์"
2. ดูดวงไพ่ยิปซีรายวัน        7. ดูดวงไพ่
3. ดูดวงไพ่ยิปซี 3 ใบ         8. ดูดวงไพ่ยิปซี 1 ใบ
4. ดูดวงไพ่ยิปซีรายเดือน      9. ดูดวงไพ่ยิปซี อดีต ปัจจุบัน อนาคต ฟรี
5. ดูดวงไพ่ยิปซีความรัก      10. ดูดวงไพ่ยิปซี แม่นๆ ฟรี
```

## 2.2 จุดตาย 5 ข้อที่ใช้โจมตีได้ทันที

**① เนื้อหาเฉพาะของแต่ละหน้า ≤ 15%**
ส่วนต่างระหว่างหน้าใหญ่สุดกับเล็กสุด = **1,560 ตัวอักษร** แปลว่า ~8,973 ตัวอักษรเป็น nav/footer ที่เหมือนกันทุกหน้า
→ **9 หน้านี้เกือบเป็น duplicate content ของกันเอง** เนื้อหาจริงต่อหน้าไม่ถึง 1,600 ตัวอักษร

**② ไม่มี meta description เลยสักหน้า**
Google ต้องเดาข้อความ snippet ให้เอง → เราเขียน description ที่ชวนคลิกกว่าได้ทันที = แย่ง CTR

**③ ไม่มี JSON-LD / structured data เลยสักหน้า (0 ทั้ง 9)**
เราใส่ครบทุกหน้าอยู่แล้ว → มีสิทธิ์ได้ rich result ที่เขาไม่มีวันได้

**④ ไม่มี hreflang · ใช้ URL มือถือแยก** (`/screen.aspx?mode=mobile&url=...`) = โครงสร้างยุค m-dot เสี่ยง duplicate

**⑤ ลิงก์ออก 207 ลิงก์ต่อหน้า + รูป 215 รูป**
น้ำหนักลิงก์ภายในเจือจางมหาศาล และหน้าหนักผิดปกติ

| *(ที่เหลืออีก 13 ผัง)* | | ใช้สูตรเดียวกัน: `ดูดวงไพ่ยิปซี + [หัวข้อ] + [จำนวนใบ]` |

**1.4 สารานุกรม 78 ใบ** — `/cards` (ตอนนี้ title = "คัมภีร์ไพ่ทาโรต์ 78 ใบ" ไม่มีคำว่ายิปซี)
```
เสนอ : ความหมายไพ่ยิปซี ไพ่ทาโรต์ ครบทั้ง 78 ใบ (ชุดใหญ่ 22 + ชุดเล็ก 56)
```
ใช้คำว่า **"ชุดใหญ่/ชุดเล็ก"** ที่คนไทยค้นจริง (ยืนยันจาก autocomplete) ควบคู่ Major/Minor Arcana

**1.5 รองรับการสะกดหลายแบบ** — "ทาโรต์ / ทาโร่ / ทาโรท์" ให้ปรากฏในเนื้อหาอย่างน้อยที่ละครั้ง

> ⚠️ **ห้ามยัดคำจนอ่านไม่รู้เรื่อง** — ผิดกฎเหล็กข้อ 10 (Human-First Copywriting)
> ใส่ให้อ่านลื่นแบบที่ไทยรัฐทำ: `"ดูดวงไพ่ยิปซี แม่นๆ | เปิดไพ่ทาโรต์"`
