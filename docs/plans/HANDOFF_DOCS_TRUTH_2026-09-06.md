ตัวเลข "จำนวนด่าน" ในเอกสารเพี้ยนมาแล้ว **6 รอบใน 6 วัน**:

นี่คือนิยามตรงตัวของหลักการข้อ 0.8 ใน [`AI_COLLABORATION_GUIDELINES.md`](../AI_COLLABORATION_GUIDELINES.md):

**ถ้าทำแต่งาน B โดยไม่ทำงาน A ปัญหานี้จะกลับมาอีกในคลื่นถัดไปแน่นอน**

## สร้างไฟล์ `scripts/qa/test-docs-numbers.ts`

### หลักการออกแบบ (อ่านก่อนเขียนโค้ด)

1. **แหล่งความจริงต้อง import จากของจริงเท่านั้น** ห้าม hardcode เลขไว้ในด่าน
   ไม่งั้นก็แค่ย้ายที่ที่ต้องแก้ด้วยมือ ไม่ได้แก้ปัญหา
2. **เอกสารประเภทบันทึกประวัติ (append-only) ต้องยกเว้น** — `INCIDENT_LOG.md` และ
   ส่วนประวัติของ `WORK_LOG.md` **บันทึกสิ่งที่จริง ณ เวลานั้น** การไปแก้เลขย้อนหลังคือการปลอมประวัติ
3. **`WORK_LOG.md` ตรวจเฉพาะบล็อกสถานะปัจจุบัน** คือทุกบรรทัด **ก่อน** หัวข้อ `### 🗓️` อันแรก
4. **เลือกจับเฉพาะรูปประโยคที่ปลอดภัย** — `(\d+) ผัง` และ `ผัง (\d+) แบบ` ไม่ชนกับ
   "ผัง 3 ใบ" หรือ "ไพ่ 10 ใบ" ที่เป็นการบรรยายจำนวนไพ่ในผัง (คนละความหมาย)
5. **มี `ALLOWLIST` แบบ Ratchet** สำหรับข้อความที่ตั้งใจอ้างเลขเก่าจริง ๆ พร้อมเหตุผลกำกับ

```ts
/**
 * QA — ยามเฝ้าตัวเลขในเอกสารแม่บท (Docs Numeric Truth Guard)
 *
 * ⚠️ ทำไมต้องมีไฟล์นี้
 * ตัวเลข "จำนวนด่านตรวจ" และ "จำนวนผัง" ในเอกสารเพี้ยนมาแล้ว 6 รอบใน 6 วัน
 * (21 → 23 → 24 → 27 → 29 → 32 ด่าน · 20 → 25 ผัง) เพราะกระจายอยู่ 8 ไฟล์
 * และไม่มีเครื่องตรวจ AI ตัวถัดไปที่อ่าน CLAUDE.md ก่อนทำงานจึงได้ตัวเลขผิดทุกครั้ง
 *
 * **บทเรียน (หลักการข้อ 0.8): กฎที่ไม่มีเครื่องตรวจ คือกฎที่จะถูกละเมิดอีกแน่นอน**
 *
 * รันด้วย: npx tsx scripts/qa/test-docs-numbers.ts
 */

import fs from "node:fs";
import path from "node:path";
import { SPREADS } from "../../src/data/spreads";
import { DECK } from "../../src/data/cards";
import { ARTICLES } from "../../src/data/articles";
import { STANDARD_SPREAD_IDS } from "../../src/lib/entitlement/limits";
import { CHECKS } from "../github-auto";   // ← ต้อง export CHECKS ออกมาก่อน

const TRUTH = {
  gates: CHECKS.length,
  spreads: SPREADS.length,
  positions: SPREADS.reduce((s, x) => s + x.positions.length, 0),
  cards: DECK.length,
  articles: ARTICLES.length,
  freeSpreads: STANDARD_SPREAD_IDS.size,
};

/** รูปประโยคที่จับ + ค่าที่ถูกต้อง — เลือกเฉพาะรูปที่ไม่ชนความหมายอื่น */
const RULES: { name: string; re: RegExp; expected: number }[] = [
  { name: "จำนวนด่านตรวจ",   re: /(\d+)\s*(?:\/\s*\d+\s*)?ด่าน/g,        expected: TRUTH.gates },
  { name: "จำนวนผัง (N ผัง)", re: /(?<!ไพ่\s)(\d+)\s*ผัง/g,               expected: TRUTH.spreads },
  { name: "จำนวนผัง (ผัง N แบบ)", re: /ผัง(?:การเปิดไพ่|พยากรณ์)?\s*(\d+)\s*แบบ/g, expected: TRUTH.spreads },
  { name: "จำนวนผัง (N Spreads)", re: /(\d+)\s*Spreads/g,                 expected: TRUTH.spreads },
  { name: "จำนวนตำแหน่ง",     re: /(\d+)\s*ตำแหน่ง(?:พยากรณ์)?/g,          expected: TRUTH.positions },
  { name: "จำนวนไพ่ในสำรับ",  re: /(?:สำรับ|ไพ่)\s*(\d+)\s*ใบ(?:ครบ|ทั้งหมด)?/g, expected: TRUTH.cards },
];

/** Ratchet — ข้อความที่ตั้งใจอ้างเลขเก่า พร้อมเหตุผลและเลขอ้างอิง */
const ALLOWLIST: { file: string; snippet: string; reason: string }[] = [];
```

> ⚠️ **กับดักของ regex `จำนวนไพ่ในสำรับ`**: มันจะจับ "ไพ่ 3 ใบ" ในคำอธิบายผังด้วย
> **ต้องทดสอบกับเอกสารจริงก่อน** ถ้า false positive เยอะให้ตัดกฎข้อนี้ทิ้งไปเลย
> ดีกว่าปล่อยด่านที่ส่งเสียงเตือนผิด ๆ จนคนเลิกเชื่อ (บทเรียน INC-0044:
> **"การรายงานผิดอันตรายกว่าไม่รายงาน — มันไปกล่าวหาคนที่ทำถูกแล้ว และทำให้คนเลิกเชื่อคำเตือนนั้นทั้งหมด"**)
> เกณฑ์ตัดสิน: ถ้ากฎไหนสร้าง false positive แม้แต่ 1 จุดบนเอกสารที่แก้ครบแล้ว → **ตัดกฎนั้นทิ้ง**

แต่ด่าน [`scripts/qa/test-seo-wave2.ts:51-53`](../../scripts/qa/test-seo-wave2.ts) ตรวจแบบนี้:

```ts
const textLength = g.introContentTh.paragraphs.join(" ").length;
// ≥ 300 คำในภาษาไทย หรือ ~800 ตัวอักษรขึ้นไป
check(`หมวด ${g.id} มีเนื้อหาบทนำเข้มข้น (${textLength} ตัวอักษร ≥ 700)`, textLength >= 700);
```

**ปัญหา 2 ชั้น**:
1. คอมเมนต์เขียน `~800 ตัวอักษร` แต่โค้ดตรวจ `>= 700` — ไม่ตรงกันตั้งแต่ในไฟล์เดียวกัน

```ts
const textLength = g.introContentTh.paragraphs.join(" ").length;
// ≥ 300 คำในภาษาไทย หรือ ~800 ตัวอักษรขึ้นไป
check(`หมวด ${g.id} มีเนื้อหาบทนำเข้มข้น (${textLength} ตัวอักษร ≥ 700)`, textLength >= 700);

// ── after ─────────────────────────────────────────────
// เกณฑ์แผนคลื่น 2 คือบทนำ ≥ 300 คำ · ภาษาไทยเฉลี่ย ~3.5 อักษร/คำ ⇒ 300 × 3.5 = 1,050 อักษรไทย
// นับเฉพาะอักษรไทยเพื่อไม่ให้วงเล็บ ชื่ออังกฤษ และเครื่องหมายวรรคตอนมาปั๊มตัวเลขให้ดูเยอะเกินจริง
const MIN_THAI_CHARS = 1050;
const thaiChars = (g.introContentTh.paragraphs.join(" ").match(/[฀-๿]/g) ?? []).length;
check(
  `หมวด ${g.id} บทนำถึงเกณฑ์ 300 คำ (${thaiChars} อักษรไทย ≈ ${Math.round(thaiChars / 3.5)} คำ ≥ ${MIN_THAI_CHARS})`,
  thaiChars >= MIN_THAI_CHARS,
);
```

> 💡 **ทำไมต้องนับเฉพาะอักษรไทย**: บทนำมีชื่ออังกฤษเยอะ (`The Fool`, `Major Arcana`, `Carl Jung`)
> ถ้านับรวมทั้งหมดจะได้ตัวเลขสูงกว่าความยาวเนื้อหาไทยจริง ๆ ~20% ซึ่งเป็นเหตุผลหนึ่งที่ด่านเดิมเขียวทั้งที่ยังไม่ถึงเกณฑ์
